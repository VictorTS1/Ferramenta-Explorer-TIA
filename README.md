# Ferramenta Explorer TIA

Projeto inicial da ferramenta Explorer TIA.

## Estrutura

- `src/`: código-fonte da ferramenta.
- `tests/`: testes automatizados.
- `docs/`: documentação do projeto.
- `scripts/`: rotinas auxiliares de desenvolvimento.
- `refs/`: referências e materiais de consulta locais, fora do Git.
- `output/`: arquivos gerados pela ferramenta, fora do Git.
